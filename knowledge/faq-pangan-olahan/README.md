# FAQ Registrasi Pangan Olahan (RAG SIGAP)

Tanya jawab resmi Rumah SiRiPO BPOM tentang registrasi pangan olahan (MD/ML), label, tabel informasi nilai gizi, dan
takaran saji. Banyak ditanyakan pelaku UMKM.

- Sumber: https://rumahsiripo.pom.go.id/informasi/faq, diambil lewat API `get_faq_ajax` pada 3 November 2026
  (robots.txt mengizinkan). Satu tanya jawab menjadi satu berkas agar dikutip utuh.
- `tanggal` adalah tanggal terakhir tanya jawab diubah di Rumah SiRiPO.
- Daftar lengkap ada di `manifest.json`.
