# Termasuk registrasi variasi apakah untuk perubahan format Informasi Nilai Gizi tanpa merubah takaran saji atau inputan zat gizi pada sistem?

Pertanyaan: Termasuk registrasi variasi apakah untuk perubahan format Informasi Nilai Gizi tanpa merubah takaran saji atau inputan zat gizi pada sistem?

Jawaban: Perubahan Format Informasi Nilai Gizi termasuk dalam registrasi variasi/ perubahan desain label sepanjang tidak merubah inputan, contoh :
1. Perubahan format dari horizontal menjadi vertikal
2. Pencantuman zat gizi yang sudah diinput tapi belum ada di tabel ING label
3. Menyesuaikan nilai ING pada label dengan nilai sebenarnya sesuai aturan pembulatan

Catatan: Jika takaran saji / inputan zat gizi berubah, maka termasuk registrasi variasi ING
