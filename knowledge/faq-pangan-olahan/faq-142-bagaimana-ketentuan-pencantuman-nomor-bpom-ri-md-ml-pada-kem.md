# Bagaimana ketentuan pencantuman nomor BPOM RI MD/ML pada kemasan ganda?

Pertanyaan: Bagaimana ketentuan pencantuman nomor BPOM RI MD/ML pada kemasan ganda?

Jawaban: Pada kemasan primer tidak wajib mencantumkan nomor BPOM RI MD/ML, jika akan mencantumkan dapat dituliskan BPOM RI MD/ML (diikuti nomornya). Untuk kemasan sekunder wajib dituliskan BPOM RI MD/ML (diikuti nomornya)
