# Bagaimana cara input pada bagian Jenis Kemasan (Berat/Isi Bersih Satuan) Sesuai NIE untuk kemasan Kaleng? Apakah perlu dijabarkan kemasan spesifiknya, misalnya Kaleng Fe atau boleh Kaleng saja?

Pertanyaan: Bagaimana cara input pada bagian Jenis Kemasan (Berat/Isi Bersih Satuan) Sesuai NIE untuk kemasan Kaleng? Apakah perlu dijabarkan kemasan spesifiknya, misalnya Kaleng Fe atau boleh Kaleng saja?

Jawaban: Untuk kemasan kaleng dapat diinput dengan disertai jenis kemasan spesifiknya, contoh “Kaleng Fe”, “Kaleng Aluminium” ATAU “Kaleng” saja.
