# Apa sajakah produk Pangan Keperluan Gizi Khusus?

Pertanyaan: Apa sajakah produk Pangan Keperluan Gizi Khusus?

Jawaban: Pangan Keperluan Gizi Khusus terbagi atas:
1. Pangan Diet Khusus (PDK) :
- PDK untuk kelompok bayi dan anak, dapat berupa : Formula Bayi, Formula Lanjutan, Formula Pertumbuhan, MPASI, makanan selingan untuk anak.
- PDK untuk kelompok dewasa, dapat berupa: Minuman Khusus Ibu Hamil dan/atau Ibu Menyusui, Pangan Olahragawan, dan Pangan untuk Kontrol Berat Badan

2. Pangan Keperluan Medis Khusus (PKMK) :
- PKMK untuk kelompok bayi dan anak, dapat berupa: PKMK untuk Pasien Kelainan Metabolik, PKMK untuk Dukungan Nutrisi bagi Anak Berisiko Gagal Tumbuh, Gizi Kurang atau Gizi Buruk, PKMK untuk Bayi Prematur, Suplemen Air Susu Ibu, PKMK untuk Pasien Alergi Protein Susu Sapi, PKMK untuk Pasien Anak Kejang Intraktabel, PKMK untuk Pasien Malabsorpsi, PKMK untuk Pasien Penyakit Hati Kronik, PKMK untuk Pasien Inflammatory Bowel Diseases, dan PKMK untuk bayi intoleransi laktosa.
- PKMK untuk kelompok dewasa, dapat berupa: PKMK untuk Penyandang Diabetes, PKMK untuk Pasien Penyakit Ginjal Kronik, PKMK untuk Pasien Penyakit Hati Kronik, PKMK untuk Dukungan Nutrisi bagi Orang Dewasa Gizi Kurang atau Gizi Buruk, PKMK untuk Pasien Kelainan Metabolik, PKMK diet ketogenik, dan PKMK dukungan nutrisi bagi pasien dewasa malnutrisi
