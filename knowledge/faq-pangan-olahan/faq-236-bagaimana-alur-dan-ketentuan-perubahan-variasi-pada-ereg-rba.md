# Bagaimana alur dan ketentuan perubahan variasi pada ereg RBA untuk semua kategori risiko?

Pertanyaan: Bagaimana alur dan ketentuan perubahan variasi pada ereg RBA untuk semua kategori risiko?

Jawaban: 1. Reg variasi Minor untuk MR, MT dan T :
Pilih id izinnya : Sertifikat Pemenuhan Komitmen Variasi Minor Pangan Olahan Proses bisnisnya : Sama dengan MR (Daftar Baru) --> Pendaftar --> SPB --> Terbit Sertifikat

2. Reg Variasi Mayor untuk MR :
Pilih id izinnya : Sertifikat Pemenuhan Komitmen Variasi Mayor Pangan Olahan Proses bisnisnya : Sama dengan MR (Daftar Baru) --> Pendaftar --> SPB --> Terbit Sertifikat

3. Reg Variasi Mayor untuk MT :
Pilih id izinnya : Sertifikat Persetujuan Variasi Mayor Pangan Olahan Wajib SNI Proses bisnisnya : Sama dengan MT (Daftar Baru) --> Pendaftar --> Verifikator 2 (TD/SPB) --> Validasi --> Terbit Sertifikat

4. Reg Variasi Mayor untuk T :
Pilih id izinnya : Izin Variasi Mayor Pangan Olahan Proses bisnisnya : Sama dengan T (Daftar Baru) --> Pendaftar --> SPB --> Evaluasi --> Verifikator 1 --> Verifikator 2 --> Validasi Direktur --> Terbit Sertifikat
