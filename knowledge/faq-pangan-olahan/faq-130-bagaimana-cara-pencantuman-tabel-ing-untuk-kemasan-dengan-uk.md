# Bagaimana cara pencantuman tabel ING untuk kemasan dengan ukuran kecil?

Pertanyaan: Bagaimana cara pencantuman tabel ING untuk kemasan dengan ukuran kecil?

Jawaban: Pencantuman tabel ING untuk kemasan kecil, dapat dicantumkan dengan beberapa cara:
1. Kemasan kecil (batas ≤ 100 cm2) dapat mencantumkan tabel ING secara Format Tabular atau Format Linier.
2. Jika luas permukaan Label sangat kecil yaitu kurang dari atau sama dengan 30 cm2 dan Pangan Olahan dijual dalam bentuk curah, maka ING dicantumkan pada wadah atau berupa 2D barcode. Contoh toples atau wadah display lainnya.
3. Jika luas permukaan Label sangat kecil yaitu kurang dari atau sama dengan 30 cm2, namun Pangan Olahan dijual dalam kemasan sekunder maka ING dicantumkan pada kemasan sekunder atau pada alamat web atau berupa 2D barcode.
4. Jika luas permukaan Label lebih dari 100 cm2, namun bentuk kemasan tidak dapat mengakomodasi format vertikal, maka pencantuman ING dapat menggunakan format horizontal.
